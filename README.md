# KION: GPT next-item и RL по прогнозу досмотра

Исследование рекомендаций KION: GPT по последовательности item-ID, supervised-головы с дополнительными признаками, history-aware reward model и RL с двумя функциями награды. Репозиторий содержит код, итоговый отчёт и компактные доказательства исследования **task 2**, завершённого 25 октября 2026 года.

Оптимизация научилась повышать прогноз досмотра. Улучшение рекомендаций по наблюдаемому следующему просмотру не установлено: supervised-голова C сохраняет наибольшую точечную MAP@10 в общем сравнении.

## Результат

Все строки используют одни и те же 4096 development-запросов и natural-пул из 1024 кандидатов. Development уже использовался при разработке.

| Модель | MAP@10 | Сравнение |
|---|---:|---|
| GPT E2 | 0,072315 | Frozen retrieval baseline |
| Supervised A | 0,082896 | Без дополнительного raw-блока признаков |
| Supervised B | 0,086458 | Часть дополнительных признаков |
| **Supervised C** | **0,096864** | Полный raw-блок признаков |
| RL completion | 0,094368 | Среднее трёх sampler-seed, matched train KL |
| RL residual | 0,096262 | Среднее тех же трёх пар, matched train KL |

Residual вычитает из прогноза reward model сглаженный средний досмотр фильма. Разность residual−completion по MAP равна **+0,001893**, условный 95% пользовательский bootstrap-интервал — **[−0,000908; +0,004520]**. Интервал включает ноль: превосходство residual над completion или C не установлено. Одна sampler-пара участвовала в калибровке, две заданы до обучения.

Масштаб работы:

- GPT E2: 3 477 437 prepared-примеров × 2 завершённые эпохи.
- Каждая supervised-голова A/B/C: 262 144 примера × 3 эпохи; GPT заморожен.
- RL: одношаговая head-only оптимизация на 512 состояниях × 1024 кандидата; GPT, reference C и reward model заморожены.
- Пятишаговая live-prefix диагностика: 16 начальных контекстов, 192 траектории, 960 шагов для исходных C/completion/residual. Она не измеряет реальные пользовательские исходы на шагах 2–5.

## Проверить клон без моделей и данных

Из корня репозитория, с Python 3.12+:

```text
python -B verify_repository.py
python -B source/verify_sources.py
python -B source/fullstudy/code/tools/verify_bundle.py --report-root source/fullstudy
python -B reproduction/kion_replay verify --bundle .
```

ML-пакеты, GPU и сетевой доступ для этих проверок не нужны. Проверяются состав Git-проекции, hashes, размеры, Python syntax, portable runtime и арифметика метрик на вымышленных примерах. Эти проверки не пересчитывают KION predictions.

## Репозиторий и полный комплект

Это **проекция исходников и результатов для Git**. В ней сохранены отчёт, рисунки, код, агрегаты, receipts и описатели входов. Численные model-input массивы, веса `.pt`/`.cbm`, raw KION, caches и полные внешние provenance payloads в Git не входят. Точный состав описан в [PROJECTION.md](PROJECTION.md) и [projection.json](projection.json).

Отдельный полный hand-in ZIP содержит ограниченные actor/RM fixtures и frozen веса. Он передаётся отдельно; ссылки на опубликованный архив и команды автоматического скачивания здесь нет. Его имя, размер, SHA256 и порядок восстановления входов приведены в [REPRODUCING.md](REPRODUCING.md).

**Сохранённые `reports/` и `reproduction/` описывают полный hand-in ZIP.** Они оставлены без изменения как часть научного snapshot. Их слова «включено в комплект» относятся к ZIP, а наличие `manifest.json` в Git не означает наличие описанных численных файлов. Для работы именно с этим клоном начните с корневого [REPRODUCING.md](REPRODUCING.md).

## Границы вывода

Результаты относятся к reused development и конечным обученным моделям; нового untouched test нет. Рост learned reward не доказывает рост реального досмотра, удовлетворённости или retention. RL обновлял только голову, а пятишаговая генерация была диагностикой frozen policies.

Ограниченный genuine replay actor и RM прошёл из новых проверочных распаковок на исходной Windows-машине с уже установленными раздельными средами. Он проверил четыре контекста × 1024 кандидата. Установка на новой машине, полный inference на 4096 запросах и новое обучение этим не подтверждены.
