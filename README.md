# KION: следующий просмотр и прогноз досмотра

Можно ли улучшить рекомендации, если оптимизировать прогноз досмотра? Каталог KION содержит фильмы и сериалы. В этой работе на данных KION сначала построена модель следующего просмотра, затем ранкер с дополнительными признаками и отдельная модель досмотра. После этого ранкер обучен с подкреплением по двум вариантам награды.

**Прогноз досмотра повысить удалось. Улучшение рекомендаций по наблюдаемому следующему просмотру не установлено.** Лучшее точечное значение MAP@10 в общем сравнении осталось у ранкера с полным набором признаков, обозначенного C.

## Как устроен эксперимент

1. **GPT по истории просмотров.** Модель получает последовательность ID фильмов и оценивает следующий фильм. Она использует представления фильмов и пользователя, но не генерирует текст рекомендаций.
2. **Смешанный список кандидатов.** Для каждого запроса собраны 1024 фильма: предложения GPT, популярные за последнюю неделю фильмы и фильмы, похожие по совместным просмотрам. Реальный следующий просмотр специально в список не добавляется.
3. **Ранкер.** Небольшая обучаемая «голова» меняет порядок кандидатов. Сравниваются три варианта: A без дополнительного блока признаков, B с частью блока и C с полным блоком. Все сохраняют представление истории из GPT; веса самого GPT на этой стадии не меняются.
4. **Модель досмотра.** Отдельная модель по истории и признакам пары «пользователь, фильм» предсказывает долю досмотра. Это прогноз, а не измеренный результат будущего показа.
5. **Обучение с подкреплением (RL).** Обучается копия головы C; исходная остаётся неизменным эталоном. Первый вариант награды, completion, использует прогноз досмотра. Второй, residual, вычитает из него сглаженный средний досмотр фильма. Отклонение от исходного ранкера ограничивается; в итоговой проверке оно сопоставимо у двух вариантов.

GPT обучался две эпохи на примерно 3,5 млн подготовленных примеров. Каждый ранкер A/B/C обучался три эпохи на 262 144 примерах. Это разный объём обучения, а не три новых прохода по всему набору GPT.

## Что получилось

В общей оценке на 4096 запросах C сохранил лучшее точечное значение MAP@10. Метрика учитывает, насколько высоко модель поставила реальный следующий просмотр среди первых десяти рекомендаций. В трёх итоговых парных запусках residual дал меньшую потерю MAP. 95% интервал разности MAP между residual и completion для этих обученных моделей включает ноль: преимущество не установлено.

В исходной диагностике на 256 запросах RL с completion повысил прогноз досмотра, но снизил MAP.

Оценочная выборка уже использовалась при разработке; нового независимого теста нет. Отдельного сравнения с ранжированием только по популярности нет. Эти результаты также не устанавливают рост реального досмотра, удовлетворённости или возврата пользователей. Пять последовательных рекомендаций проверены как диагностика генерации, без реальных откликов на последующие шаги.
