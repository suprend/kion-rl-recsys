# Повторное обучение голов на готовых признаках

Этот отдельный этап заново обучает A, B и C на всех 262 144 примерах за три эпохи. Он использует сохранённые представления GPT и признаки. Он не восстанавливает их из исходного KION и не обучает GPT или RM.

В этой поставке проверены план запуска и тесты адаптера. Само обучение не запускалось, совпадение новых весов с историческими не проверено.

## Входы

Нужен неизменённый каталог банка: `bank.json` и десять массивов, около 36,3 ГБ. Файлы перечислены в [реестре входов](profiles/head-bank-inputs.json), содержимое банка в архив репозитория не включено. SHA-256 `bank.json`:

```text
7eb271a5c5c44f33c2b22dfe26ce120bbd7016aeeba67b6fef817ad3e183ff5a
```

Пути к старому GPT внутри `bank.json` сохраняются как сведения о происхождении. Для этого этапа файлы GPT по этим путям не открываются. Вычислительные входы состоят из самого банка; для его построения зависимости значительно шире.

Для будущего обучения нужна среда Actor из [ENVIRONMENTS.md](ENVIRONMENTS.md) и CUDA. Режим плана использует только стандартную библиотеку Python.

## Проверить план без обучения

Из корня распакованного репозитория, заменив пути на абсолютные пути своей машины:

```powershell
python -B reproduction/train_heads.py --bank-dir C:/data/head-bank --output-dir C:/runs/heads-new --bank-manifest-sha256 7eb271a5c5c44f33c2b22dfe26ce120bbd7016aeeba67b6fef817ad3e183ff5a --plan-json C:/runs/heads-plan.json
```

`heads-plan.json` должен отсутствовать, а его родительский каталог должен существовать. Каталог `heads-new` также должен отсутствовать. План не создаёт его, не импортирует библиотеки обучения и не читает большие массивы. Он проверяет хеш `bank.json`, имена, размеры и объявленные формы массивов. Это не полная проверка содержимого массива.

Для отдельной проверки входов скопируйте [roots.example.json](profiles/roots.example.json) вне репозитория и укажите путь `HEAD_BANK`. Команда ниже только сверяет наличие и размеры:

```powershell
python -B reproduction/input_inventory.py --manifest reproduction/profiles/head-bank-inputs.json --roots C:/runs/roots.json --output C:/runs/bank-inspect.json
```

Код завершения 1 в этом режиме означает, что содержимое ещё не проверено. Добавление `--verify` прочитает все 36,3 ГБ и сверит хеши. Код 0 означает совпадение обязательных файлов с реестром; он не подтверждает работоспособность CUDA или результат обучения. Выходной JSON должен быть новым и находиться вне каталога входов.

## Запускать только при отдельном решении об обучении

Для обучения уберите из команды `--plan-json` вместе с путём к JSON и добавьте `--execute-training --max-seconds 14400`. Параметры сохранения плана и запуска обучения несовместимы. Этот режим действительно запускает обучение; при подготовке отчёта он не выполнялся.

Адаптер вызывает сохранённый научный код без изменения архитектуры и расписания: три эпохи, пакет 128, 6144 обновления каждой головы, seed 20261024. Перед обновлениями исходный код сверяет хеши всех десяти массивов. Старые проверки по времени изменения файлов для ускорения проверки не используются.

Временной предел и резерв места проверяются между операциями исходного кода. Это не принудительное завершение процесса: отдельная операция может закончиться позже лимита. При остановке нельзя объявлять неполный запуск завершённым. Новый адаптер не поддерживает продолжение частичного обучения.

Полный путь от исходного KION до GPT, банка признаков, RM и RL пока остаётся [историческим рецептом](README.md#исторический-рецепт-обучения), а не проверенной переносимой командой.
