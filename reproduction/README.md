# Воспроизведение KION

Текущая точка входа: [REPRODUCING.md](../REPRODUCING.md). Она задаёт команды, получение входов и границы проверки для нынешнего клона. Этот документ обновлён вместе с ней; прежняя инструкция полного архива больше не описывает состав текущего клона.

| Путь | Доступные входы | Результат |
|---|---|---|
| Проверка исходников | Текущий клон | SHA256, размеры, синтаксис и синтетическая арифметика метрик |
| Текущая таблица и интервалы | `saved-metrics64k/` | 65536 запросов, пересчёт метрик и bootstrap по пользователям |
| Историческая таблица | `saved-metrics/` | Метрики прежних 4096 запросов |
| Проверка сохранённых actor/RM | Два набора входов из отдельно полученного прежнего полного ZIP | Предсказания для четырёх контекстов; пакет GPT из 16 историй |
| Исходные данные → признаки → обучение | Исходные данные, модели, банки признаков, выборки и кеши | Исторический рецепт; полного переносимого запуска в текущей поставке нет |

В малом наборе для проверки моделей нет наблюдаемых целевых меток: он проверяет вычисления, но не пересчитывает MAP. Ранговый пересчёт, напротив, проверяет метрики без запуска моделей.

[INPUTS.md](INPUTS.md) описывает входы, [ENVIRONMENTS.md](ENVIRONMENTS.md): среды и точность вычислений, [HAND_IN.md](HAND_IN.md): передачу. Старые JSON-задания сохраняют параметры исследования; их пути и сроки не являются командами текущего запуска.

## Сохранённые рисунки

Для чтения отчёта пересборка рисунков не нужна. Два прежних скрипта принимают включённые агрегаты. В среде для рисунков из [ENVIRONMENTS.md](ENVIRONMENTS.md), из корня клона:

```text
python -B source/fullstudy/code/tlab-recsys-2026/artifacts/task2-kion/c-rl-final-20261025-r1/interpretation/plot_results_v4.py --input evidence/fullstudy/plot-data-screen.json --labels evidence/fullstudy/figure-provenance/screen/labels.json --output ../kion-figures-screen
python -B source/fullstudy/code/tlab-recsys-2026/artifacts/task2-kion/c-rl-final-20261025-r1/interpretation/plot_results_v4.py --input evidence/fullstudy/plot-data-full.json --labels evidence/fullstudy/figure-provenance/full/labels.json --output ../kion-figures-full
```

`python` здесь означает интерпретатор среды для рисунков. Выходной каталог должен отсутствовать, родительский каталог должен существовать. Модели и исходные CSV не нужны. Команды строят изображения из агрегатов, не пересчитывая метрики из предсказаний. Историческое совпадение 13 PNG относится к прежней среде. В новой среде шрифты и изображение могут отличаться; новый запуск этих скриптов в текущей редакции не заявляется.

## Исторический рецепт обучения

Рецепт сохраняет параметры исследования. Точные задания: [source-requests.json](../source/fullstudy/code/recipes/source-requests.json), [execution-stage-index.json](../source/fullstudy/code/recipes/execution-stage-index.json), [источники согласованного KL](../source/matched-kl/selection-final-r1.json). Недостающие входы: [excluded-inputs.json](../source/fullstudy/code/recipes/excluded-inputs.json); реализации и платформенные зависимости: [SOURCE_CLOSURE.md](../research/SOURCE_CLOSURE.md).

1. Получить KION и сверить три CSV по [INPUTS.md](INPUTS.md). Использовался полный `data_original.zip`; отдельный `interactions.csv.zip` был усечён. Ненаблюдаемые пары не получают метку RM 0.
2. Подготовить словарь, отображения ID и временные разбиения через `ready-pack-20261020/provider/runtime-native-r5/scripts/kion_prepare.py` с `--context 64 --max-train 1000000000 --max-eval 1000000000 --seed 2026`. Значения по умолчанию 32/150000/3000 не соответствуют полному рецепту. Обучение: до 9 августа 2021; разработка: 9–15 августа; тест в метаданных: 16–22 августа. Размеры: 3477437 / 158760 / 167432. Выборка разработки использовалась многократно.
3. Восстановить время запросов, признаки строго из прошлого, хеши отображений и схем, граф кандидатов, 1068 основных + 2 признака источника, фиксированные выборки и кеши E5. Для 161 внешнего признака есть [метаданные происхождения](external-provenance/INDEX.json), но отсутствуют 149 банков по датам, исходные ответы Wikimedia и агрегаты MovieLens.
4. Обучить исходный GPT по ID: hidden 256, layers 4, heads 4, bottleneck 32, person_dim 32, context 64, B128, AdamW lr 1e-4, weight decay 0,01, seed 2026. Принятая E2-линия завершила две эпохи, 54470 обновлений и 6954874 предъявления при расписании на пять эпох, продолжая состояние оптимизатора, scaler и генератора случайных чисел. Новый двухэпоховый запуск с другим расписанием не воспроизводит эту историю. Дополнительные отрицательные примеры равномерно выбирались из retrieval top128; CE по всему словарю сохранялась.
5. На фиксированном E2 построить банк 262144: прежние 32768 плюс 229376 примеров. Обучить A/B/C по три эпохи, 6144 обновления, B128, положительный + 31 фиксированный отрицательный пример. C использует 1068 основных + 2 признака источника; q/v/GPT фиксированы. Оценка: естественные 1024 кандидата без вставки цели; неизвестные и отсутствующие в пуле цели остаются нулями в знаменателе.
6. Для RM использовать наблюдаемый `watched_pct/100`. Обучение: до 2 августа; подбор и калибровка: цели 2–8 августа, непересекающиеся пользователи и история до 2 августа. Размеры 100000 / 20000 / 20000; две CatBoost-модели с историей и без неё: depth 4, 160 iterations, lr 0,05, L2 leaf 10, seed 2026, два CPU-потока. RM-r2 меняет калибровку при прежних деревьях. Схема RM: 2079 признаков контекста + 2008 кандидата; она отличается от C.
7. Зафиксировать 512 обучающих и 256 проверочных контекстов, исключив пользователей и контексты подбора/калибровки RM. Проверить поддержку RM, отображения ID, масштаб и начальное состояние. Completion H1 обучает только голову: `E_pi[r_eff] − beta KL(pi||C)`, beta 0,5, Adam lr 1e-5, weight decay 0, clip 1, B16, 1000 обновлений, seed 20261024, контрольные точки 0/250/500/1000. Encoder, reference и RM фиксированы.
8. Residual использует `r_RM(s,i) − m_fit(i)`: среднее по наблюдаемым обучающим данным до 2 августа, коэффициент 1; преимущество неподдержанных пар: 0, softmax/KL по всем 1024 действиям. Исходный beta 0,5; в продолжении с согласованным KL beta 0,1627403 выбран на обучении. Три пары seeds: 20261024/25/26.
9. Исторические оценки: 256 и 4096 запросов с парным bootstrap по пользователям. Пятишаговая диагностика выполнена только для исходных C, completion seed24 и residual beta 0,5; для шести голов с согласованным KL её нет. На шагах 2–5 нет наблюдаемых контрфактических меток: кандидаты и состояние RM фиксированы, GPT q меняется после добавления выбранного фильма. Уникальность обеспечена запретом повторов.

Для полного запуска нужны отсутствующие входы и адаптация скриптов: прежние исполняемые файлы и пути PAS, кеши на C:/D:, SQLite на E: с требованием 110 GB, отдельный Windows backend RM и раздельные версии NumPy. Простая замена путей в JSON этого не решает; подробности сохранены в [SOURCE_CLOSURE.md](../research/SOURCE_CLOSURE.md). Ретроспективные метаданные и агрегаты последних просмотров сохраняют временные ограничения [отчёта](../REPORT.pdf).
