# Подготовка временных разбиений из raw CSV

`prepare_data.py` запускает сохранённый `kion_prepare.py` из
`source/fullstudy/code/`, проверяя закреплённый SHA256 исходника. Алгоритм остаётся
неизменным: три raw CSV преобразуются в NPZ разбиений, метаданные и базовые признаки
объектов. Это отдельный этап подготовки данных.

Запускайте из корня репозитория с actor-интерпретатором из
[ENVIRONMENTS.md](ENVIRONMENTS.md). Raw CSV нужно предоставить самостоятельно;
происхождение и ожидаемые хеши описаны в [INPUTS.md](INPUTS.md).

```powershell
$actorPython = 'C:/your-actor-environment/python.exe'
& $actorPython -B reproduction/prepare_data.py --input 'D:/raw/kion/full' --output 'D:/prepared/kion-context64' --python $actorPython
```

По умолчанию команда выводит JSON-план без записи файлов. Она читает и хеширует
только исходник размером до 1 MiB, проверяет наличие и размеры трёх CSV через stat,
а также требует новый выходной каталог вне дерева raw данных. Содержимое CSV
не читается; ожидаемые хеши помечены как **непроверенные**. План не импортирует
NumPy/Torch, не сканирует каталоги и не запускает указанный интерпретатор.
Совместимость его окружения требует отдельной проверки. Путь launcher сохраняется,
включая symlink Python внутри venv.

Для явно разрешённого запуска подготовки добавьте
`--execute-prepare --timeout-seconds 3600`. Этот режим полностью хеширует три CSV,
отклоняет несовпадение байтов, создаёт новый выходной каталог и
`prepare-launch.json`, затем запускает исходный CLI с ограничением времени.
При ошибке частичный результат сохраняется; повторный запуск требует нового
каталога. Не изменяйте CSV и исходник одновременно с выполнением команды.

Точные аргументы исходного CLI:

```text
<actor-python> -B <retained-source>/kion_prepare.py --input <raw-directory> --output <new-directory> --context 64 --max-train 1000000000 --max-eval 1000000000 --seed 2026
```

Эти параметры заменяют меньшие значения по умолчанию. Словарь обучается на датах
до 9 августа 2021 года. Оценочная часть охватывает 9–15 августа, тестовая часть охватывает 16–22 августа.
В каждом окне сохраняются все цели первой целевой даты пользователя, история
фиксируется до начала окна. Обучающие истории исключают взаимодействия в день
цели. В test история может включать наблюдения validation; неизвестные цели
остаются UNK. Предел каждого разбиения составляет миллиард строк.

Успешный запуск означает успешное завершение исходного CLI; эквивалентность
результатов receipt не подтверждает. Перед дальнейшим использованием отдельно
сверьте context 64, словарь и отображение ID, даты целей, число сохранённых строк
3 477 437 / 158 760 / 167 432 для train/validation/test и идентичности манифестов,
нужные последующим этапам. Сравнивайте содержимое массивов: байты NPZ могут
различаться из-за временных меток ZIP. Исторические манифесты адаптер не переписывает.

Проверка: `python -B -m unittest discover -s reproduction -p test_prepare_data.py -v`.
Тест исходного алгоритма использует NumPy и шесть синтетических строк; тесты
launcher подменяют subprocess и используют маленькие CSV. Они проверяют цели
одной даты, фиксированные истории и UNK, но не доказывают эквивалентность полного
датасета. При реализации полный preprocessing и обучение не запускались.
