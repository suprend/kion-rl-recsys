# Evidence for the unified KION task 2 report

[INDEX.json](INDEX.json) is the source-to-package map for the frozen compact evidence and fourteen PNG/SVG figure sets from the two completed studies. Each record includes the original source path, SHA-256, byte size, local package path and link relative to `reports/REPORT.md`.

- `fullstudy/` contains accepted full-study reader exports, compact scientific/visual proofs and frozen source/dependency indexes.
- `matched-kl/` preserves compact source-relative protocols, completed fit metadata, train-KL diagnostics, screen/full analyses and accepted independent proofs.
- `raw-provenance/` contains two metadata-only pinned archive/member hash manifests; the CSV payloads are external.
- Figure payloads are in `../reports/figures/fullstudy/` and `../reports/figures/matched-kl/`.
- [reproduction/INDEX.json](reproduction/INDEX.json) separately records the actual new no-training fixture exports, fresh candidate extractions and successful actor/RM numerical inference.
- `reviews/` contains the independent current release reviews; the final archive manifest enumerates the whole delivery.

The frozen study evidence listed in INDEX.json consists of exact-byte copies, collected without model/array access, raw user histories, per-query outcome CSVs, training, numerical recomputation or native jobs. The paired-metrics CSVs are small aggregate comparison tables. No previous whole archive is needed to read the unified report. These statements describe the evidence collection. The separately documented numerical reproduction fixture contains transformed item-token prefixes and user features with direct source user IDs omitted; anonymity is not established. Its input manifests and actual numerical acceptance are described by the reproduction package, separately from the frozen evidence-copying step.

Absolute paths inside frozen JSON are historical provenance metadata. The portable paths and report link names are the index record `path` and `report_link`. A historical source receipt does not assert that a new numerical replay has run in this submission.

The full-study bibliography is [references.md](fullstudy/report-provenance/references.md). The captured task condition is [source-condition.md](fullstudy/source-condition.md).

The frozen `fullstudy/i0-report.md` mentions a historical `../evidence-index.json` in a code span. In this package its original index is [source-evidence-index.json](fullstudy/report-provenance/source-evidence-index.json); use [INDEX.json](INDEX.json) for the unified link map. The source copy is preserved exactly.
